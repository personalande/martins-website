# Informações Necessárias (CONTENT_REQUIRED)

Este documento centraliza as informações institucionais, operacionais e técnicas pendentes que devem ser fornecidas pela Ferragens Martins para a versão final de produção.

## 1. Dados Institucionais e Legais
- **CNPJ**: CNPJ oficial da Ferragens Martins para inserção no Rodapé e Políticas de Privacidade/Termos de Uso.
- **E-mail do DPO**: E-mail do encarregado de proteção de dados para conformidade com a LGPD nas Políticas.
- **Textos Jurídicos Completos**:
  - Termos de Uso do site.
  - Política de Privacidade completa.
  - Declaração de conformidade com Cookies.

## 2. Conteúdo de Mídia (Imagens Reais)
- **Logotipos**: Arquivo SVG ou PNG do logotipo oficial (Substituir o logo em texto no SiteHeader/SiteFooter).
- **Fachadas das Lojas**: Fotos das fachadas para as páginas individuais de lojas (`/lojas/vila-sao-vicente` e `/lojas/vila-itibere`).
- **Imagens de Destaque**: Banners de campanhas/promoções da página inicial.
- **Imagens de Artigos do Blog**: Fotos reais de capas para dicas de ferramentas/obras.

## 3. Dados Operacionais
- **Números de WhatsApp**: Números dedicados adicionais caso haja mudança nas contas de atendimento de orçamentos.
- **Emails de Contato**: Contas de email para onde as mensagens enviadas através do formulário de contato devem ser encaminhadas.
- **Integração com ERP / Estoque**: Definição técnica da API do software de gestão comercial para sincronização de estoque automático futuro.
